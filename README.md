TokenLuster leverages Smart Distributed Architecture to deliver Real-time Data adaptive Auto-Scaling via an integrated Framework and Execution Engine.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/TokenLuster.git`
2. `cd TokenLuster`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
